# @indibit/tba3-elements

Angular-Komponenten für Auswertungsdaten im [TBA-III-Format](https://github.com/indibit-eu/tba3).
Jedes Element bekommt Value-Groups als Input und zeigt sie an.

Doku, Demo und Quellcode: [https://github.com/indibit-eu/tba3-elements](https://github.com/indibit-eu/tba3-elements)

Das Theme bindest du nach Bootstrap ein:

```scss
@use '@indibit/tba3-elements/styles/theme';
@use '@indibit/tba3-elements/styles/tables';
@use '@indibit/tba3-elements/styles/charts';
```
